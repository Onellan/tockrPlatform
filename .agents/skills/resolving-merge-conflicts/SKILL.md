# tockrPlatform Merge Conflict Resolution

Before resolving, inspect Git state and preserve unrelated work. Do not use hard reset or mechanical `ours`/`theirs` selection to make the conflict disappear.

Reconstruct intent from higher product authority, active plan, tests, current history and compatible changes. Preserve both compatible changes where possible, especially governance/history/security/document-boundary rules.

Resolve semantically, validate the resulting behaviour and avoid opportunistic refactoring. Conflict-resolution authority does not itself authorise commit, push or force-push.
