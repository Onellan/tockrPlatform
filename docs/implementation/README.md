# Tockr Platform implementation programme

Implementation plans translate the approved Platform Foundation authority into
ordered delivery work. Plans do not replace `docs/architecture/` or
`docs/contracts/`, and they do not claim implementation evidence.

The programme plan is [Priority PF](../../plan/pf-platform-foundation.md). A
terminal Slice is recorded only in `IMPLEMENTED.md` after independent review,
independent acceptance and exact-candidate local validation have passed. The
execution queue is maintained in [the incomplete-plan tracker](../../plan/incomplete.md);
terminal plans are retained immutably in [plan/completed](../../plan/completed/).

PF-B11 is the terminally certified forward Platform extension for the versioned
consumer read-authority contract required by CTRL and IMS. S01, S01-R1, S02,
S03 and S04 are terminal. The published handoff does not implement consumer
cutover.
