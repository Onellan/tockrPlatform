# Tockr Platform implementation programme

Implementation plans translate the approved Platform Foundation authority into
ordered delivery work. Plans do not replace `docs/architecture/` or
`docs/contracts/`, and they do not claim implementation evidence.

The active programme is [Priority PF](../../plan/active/priority-pf.md). A
terminal Slice is recorded only in `IMPLEMENTED.md` after independent review,
independent acceptance and exact-candidate local validation have passed.
