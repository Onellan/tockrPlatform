# PD-D8-S02 WP-PD8S02-03 — Compatibility usage ledger

**Date:** 2026-09-26  
**Scope:** Authority migration seams shared by TockrPlatform, TockrCTRL and
TockrIMS. This is an inventory and retirement control record; it does not
activate authentication or membership cutover and it does not remove a
compatibility seam.

## Decision and evidence rules

Platform is the only shared-authority writer in the Platform-authoritative
mode. CTRL and IMS local shared writers are retained as explicitly selected,
fail-closed rollback/pre-cutover paths. Normal consumer requests read the
consumer projection and do not synchronously call Platform. Product-owned
project, discipline, programme, control and commercial records remain local.

"Source-active" below means the path, schema or flag is present in the exact
source candidate and is covered by repository tests. No production request
counter or deployment telemetry was supplied in these repositories, so a
source-active row is not represented as zero-use. A row may be retired only
after a current deployment counter/log extract proves zero use, a disposable
rollback rehearsal succeeds, and the named cutover owner accepts the change.

## Retirement gates

1. Capture deployment counters/logs for every source-active legacy path and
   compatibility route/adapter. A repository grep or passing test is not a
   zero-use claim.
2. Reconcile the counter window with the exact Platform/CTRL/IMS source SHAs
   and configuration snapshots. Any unknown deployment or stale consumer keeps
   the row retained.
3. Rehearse local-mode authentication and shared-membership rollback from the
   named restore point, including session invalidation, projection replay and
   audit correlation.
4. Resolve every IMS `unresolved` role mapping and every D7 mapping record
   before retiring role compatibility columns or local writers.
5. Obtain independent engineering review and tester acceptance for the exact
   retirement candidate, then update this ledger and the applicable D7/D8 plan.
6. Remove compatibility artifacts only in a separate additive/reversible
   change. Preserve historical actor IDs, audit events, source references and
   rollback receipts.

**Current disposition:** all rows are retained according to the dispositions
above. No compatibility path, writer, table or flag was removed by this
ledger.
